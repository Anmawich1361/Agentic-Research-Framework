# Historical Agentic Research Framework Planning Bundle

This historical bundle captures phase-planning material that preceded the
current V1 implementation. Prefer the root `README.md`,
`docs/CURRENT_STATUS.md`, and `docs/PROJECT_COMPLETION_PLAN.md` for current
behavior.

Recommended use:

1. Read [`PROJECT_REVIEW_CURRENT_STATE.md`](PROJECT_REVIEW_CURRENT_STATE.md).
2. Use [`ROADMAP_PHASE_9_TO_14.md`](ROADMAP_PHASE_9_TO_14.md) as the historical
   build plan.
3. Give Codex one prompt at a time from
   [`CODEX_PHASE_9_TO_14_PROMPTS.md`](CODEX_PHASE_9_TO_14_PROMPTS.md).
4. Use [`QUALITY_GATES_AND_EVALS.md`](QUALITY_GATES_AND_EVALS.md) as the
   acceptance checklist.
5. Use
   [`LIVE_SMOKE_AND_ARTIFACT_REVIEW_PLAYBOOK.md`](LIVE_SMOKE_AND_ARTIFACT_REVIEW_PLAYBOOK.md)
   after live runs.
6. Track cleanup work in [`TECH_DEBT_REGISTER.md`](TECH_DEBT_REGISTER.md).

The isolated phase-9 prompt is archived in:

```text
NEXT_CODEX_PROMPT_PHASE_9.md
```

The root README is now the current project entrypoint. Keep future planning
material in this directory unless it belongs in durable product documentation.
