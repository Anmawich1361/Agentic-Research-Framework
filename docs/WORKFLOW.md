# Workflow

## Step 1: Intake

Input:

```text
Research [target] for [purpose].
```

Output:

- target
- target type
- purpose/lens
- depth
- geography
- time horizon
- deliverable
- key questions

## Step 2: Research plan

The plan translates the charter into answerable questions and report sections.

Example sections:

- business overview
- industry context
- competitors
- financial profile
- recent developments
- risks
- questions to ask

## Step 3: Source discovery

Find candidate sources and classify them.

The source discovery agent should avoid deep report writing. Its job is source collection and classification.

## Step 4: Source scoring

Score sources using deterministic code. Agents can provide rationale, but code computes the scores.

## Step 5: User checkpoint

Pause before deep research.

Checkpoint includes:

- charter
- source map
- early read
- gaps
- recommended research angle
- questions for user

## Step 6: Deep research

Extract evidence and run specialist analysis.

## Step 7: Evidence ledger

Store every important claim.

## Step 8: Synthesis

Generate a report from the evidence ledger and source map.

## Step 9: QA

Review the draft. Flag issues. Revise or mark as needs review.
