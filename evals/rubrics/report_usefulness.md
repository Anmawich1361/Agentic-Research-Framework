# Report Usefulness Rubric

Checks whether the report is structured for the user request and selected template.

Pass criteria:
- Every `expected_report_sections` heading appears exactly in the draft report.
- The report distinguishes facts, inferences, and open questions where needed.
- Meeting prep reports include practical unknowns and questions to ask.

Common failures:
- Generic headings that do not match the selected template.
- Missing meeting-prep unknowns.
- Advice that is not anchored to the user lens.
